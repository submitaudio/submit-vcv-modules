# Submit Lab 2.0.0 Beta 1

Submit Lab is the public beta channel for experimental Submit Audio modules.
It installs alongside the normal Submit plugin and does not replace existing
Submit modules.

## Included modules

- **Circles** — An always-quantized circular eight-step sequencer with musical
  flow modes, four scale-chain slots and a slower dedicated sub track.
- **SUB** — A monophonic bass voice with an analog-style upper layer, a deep
  octave-down sub layer, warm drive, accent response and six CV modulation
  inputs.

No other Submit Audio modules are included in this beta.

## Beta 1 highlights

### Circles

- Eight stored and individually enabled sequence steps.
- Forward, Reverse, Pendulum, Drunk and Random flow modes.
- Four-slot Scale Chain with independent scales and bar lengths.
- Dedicated slow `SUB V/OCT` and `SUB GATE` outputs.
- Musical Dice function with Subtle, Musical and Wild characters.
- Patch storage for notes, enabled steps, scales, flow and sub-track settings.

### SUB

- Expressive upper bass voice with a separately mixed sub layer one octave
  lower.
- Nine octave positions from -4 to +4.
- Fine tuning of the upper layer while the sub layer remains pitch-stable.
- Warm compensated drive instead of a simple volume increase.
- Smoothed Accent response for short gates.
- CV control for Filter, Resonance, Envelope Amount, Decay, Sub and Drive.

## Downloads

Choose the package matching your platform:

- `mac-arm64` — Apple Silicon Macs
- `win-x64` — 64-bit Windows
- `lin-x64` — 64-bit Linux

Quit VCV Rack before replacing or installing plugin packages, then restart Rack
and search for the **Submit Lab** brand.

## Beta notice

This is test software. Sounds, behaviour and presentation may still change.
Please keep important patches backed up. Submit Lab patches use the separate
`SubmitLab` plugin identity and therefore remain distinct from normal Submit
patches.
