# Chain changelog

## v2.23.0 (release candidate)

- Added a patch-saved Mute CV mode menu: Gate (default, unchanged) or Toggle. In Toggle, each rising edge switches the channel mute button, including its existing FX return behaviour. Held gates do not retrigger; loading a patch or changing modes while high does not toggle the saved state.

- Added smooth 10 ms mute and unmute fades for both channel buttons and mute CV inputs, including the existing button-controlled FX return scaling.
- Preserved stereo routing, send chains, COMP/CV behaviour and parameter IDs. Muted patches start silently.

## v2.19.0 (2026-08-22)

- Included in Submit 2.19.0 with no module-specific functional changes.

## v2.18.0

- Updated the panel and compact rotary controls to the current Submit Audio design.
- Preserved the complete mixer routing, COMP/CV behaviour and patch compatibility.
