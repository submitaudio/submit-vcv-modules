# Sum S4 Changelog

## v2.19.0 (2026-08-22)

- Added the initial public version of the compact four-channel stereo mixer.
- Added per-channel level and clickless mute controls.
- Added right-input normalisation from the left input for mono sources.
- Added stereo Chain input and output for use within the Submit Chain family.
- Existing patches are unaffected because Sum S4 uses a new module slug.
- VCV Rack CPU stress testing passed for the 2.19.0 release candidate.
