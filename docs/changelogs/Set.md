# Set Changelog

## v2.19.0 (2026-08-22)

- Added the initial public version of the clocked performance timer.
- Added panel run/pause/resume behaviour without losing elapsed time.
- Kept the panel timer reset separate from the lower pulse-phase reset input.
- Added selectable quarter-note, half-note and whole-note pulse output from a 1 PPQN clock.
- Existing patches are unaffected because Set uses a new module slug.
- VCV Rack CPU stress testing passed for the 2.19.0 release candidate.
