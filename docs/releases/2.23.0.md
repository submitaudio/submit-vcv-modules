# Submit 2.23.0

Release candidate. The Submit Audio collection remains at 22 modules, with updates to Chain, Chrono, Sweep, Loop, Sync and SUB. No additional beta modules are included.

## What's new

- **Chain:** choose Gate or Toggle for Mute CV and save the choice with your patch. Mute and unmute transitions now use smooth 10 ms fades, including the existing button-controlled FX return behavior.
- **Chrono:** all six Heads settings now shape the normal stereo wet output, even with Feedback at zero and Surge off. The selector and tooltips follow the panel order: ALL, TRP, DOT, QTR, DUB, SUB from top to bottom. Offset, Spread and tape movement apply to the audible head mix.
- **Sweep:** restored passband level and refined the low-cut/resonance transition near the centre. Reset now returns smoothly to the unfiltered centre in approximately 38 ms.
- **Loop:** new V4 panel with a Play/Stop button and gate input. With Sync enabled and Clock connected, STOP finishes the current loop and START waits for the next quarter-note edge. This also works in reverse and with 4 PPQN input. A second request cancels a queued action. Without clock sync, playback pauses and resumes immediately. Short audio fades and patch-saved playing state are included.
- **Sync:** new START CV Trigger/Gate mode. Gate mode follows the input's high/low state, with manual overrides until the next gate transition. Stop retains priority.
- **SUB:** smoother low-bass note transitions and short frequency smoothing for both oscillators reduce abrupt changes during long decays.

## Existing patches

All 22 module slugs remain unchanged. Existing parameter and port IDs are retained; Loop's new controls are appended.

- **Chrono:** stored selector values remain unchanged, but the corrected combinations at SUB, DUB, TRP and ALL can change existing patches. QTR and DOT retain their combinations. All positions now affect the normal wet output.
- **Sweep:** the revised filter response and restored passband level can change existing patches. The filter is not a speaker-protection limiter.
- **Chain:** Gate remains the default Mute CV mode.
- **Sync:** older patches use Trigger mode.
- **Loop:** older patches retain automatic playback. Newly saved patches remember the playing state; an already-high gate at load does not override it.

## Validation

The six changed modules passed actual-DSP regression tests at 44.1, 48 and 96 kHz. José confirmed Rack listening and CPU stress approval on 27 September 2026.

The public macOS ARM64 build contains exactly the approved 22 modules. The manifest uses `GPL-3.0-or-later`; module tags match the official Rack 2 tag list.

Windows x64 and Linux x64 CI builds and final package checks are required before publication and VCV Library submission. This candidate has not yet been submitted.
