# Burst

Burst is een dual-voice percussie module voor VCV Rack.

## Concept

Burst bestaat uit twee verschillende voices:

- Voice A → body / kick / low-end
- Voice B → attack / noise / metallic

De module is ontworpen voor snelle, muzikale percussie met een levendig en organisch karakter.

## Functies (gepland)

- 2 trigger inputs (A / B)
- 2 voices met eigen karakter

### Per voice:
- Tune
- Decay
- FM
- Texture / Noise

## Globale controls

- Interact (A ↔ B beïnvloeding)
- Drift / Chaos
- Mix

## Output

- A output
- B output
- Mix output

## Doel

Een compacte, speelse percussie module die direct goed klinkt maar ook diepte biedt.
